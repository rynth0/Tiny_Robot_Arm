# Tiny_Robot_Arm
Original files are the code and wiring diagram for the robot in the following video:
YouTube Video: https://youtu.be/6de55CUOTI4
STL Files: https://www.thingiverse.com/thing:6142959

I am using this arm for another in-progress project (see profile -> PROJECT NAME) to function as the 
'neck' of the robot (think Wall-E). In this repository I'll note down my experience with it, and any changes
I made to the design or code.

Project started as part of the Edinburgh Award for Student Technicians in the summer of 2026.
